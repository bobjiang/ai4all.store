## 2. Landing Page

High-converting course landing pages all share the same bones: clear promise, benefits, social proof, and one clean CTA.  ￼

### 2.1 Page structure (simplified)

**1.	Hero section**
- Headline: clear outcome + specific audience
- e.g. “AI Skills for Teens: A Hands-On Introduction to Artificial Intelligence”
- Subheadline: what they’ll walk away with
- e.g. “Understand how AI works, use tools like ChatGPT safely, and build a real mini-project – no coding experience required.”
- Primary CTA: “Join the Waitlist” or “Apply for the Next Cohort”

**2.	For parents: problem → outcome**
- Pain points: “School hasn’t caught up”, “Kids use AI without guidance”, “Worried about plagiarism / cheating.”
- Outcomes: confidence using AI ethically, better study skills, portfolio piece for future applications.

**3.	Course snapshot**
- Duration, format, age range, prerequisites.
- Short module list (4–6 bullets).
- Tools used (Google Colab, Antigravity or equivalent, Teachable Machine, etc.).

**4.	Proof & credibility**
- Early testimonials once you run pilot cohorts.

**5.	Details + FAQ**
- “Is this safe?”, “Is it all screens?”, “What if my kid is shy?”
- Clear refund / reschedule policy.

**6.	Final CTA**
- Repeated “Join the Waitlist / Enroll Now”.

### 2.2 Pre-sell, don’t just “announce”

- Run a pilot cohort at a discount in exchange for feedback + testimonials.
- Goal: Fill 8–12 seats at a fair test price (say AU$199–$399 for 4 weeks) and measure:
- Show-up rate
- Completion of project
- NPS / “Would you recommend to a friend?”
